# SETUP

Needs the Idea recap and the AI job. If either is missing, run that first.

One reply, nothing else in it:

Question 1: How do you picture people using this: on a phone, on a computer, inside a tool they already use, or something else?
Question 2: What information would it run on, and which of it do you have today?

If the founder already answered either, skip it. If they answer "idk" to one, take your best guess and mark it.

Then work out the setup silently, from everything so far. Do not show it here; it appears once, in the Choices recap. Seven rows:

1. **Where people use it.** From question 1.
2. **How it starts.** The user comes looking, a staff member sends it, it arrives on a schedule, or it triggers from an event.
3. **Sign-in.** None, a code or link, a phone number, an account, or through an organization the user already belongs to.
4. **What it does.** The AI jobs picked, in one plain sentence.
5. **What the user gets.** What lands in their hands, from the founder's words. Never invent a component they did not mention.
6. **What the AI works from.** Each source from question 2 with a status: **have** (exists, usable today), **partial** (some exists, or access is unconfirmed), **build** (must be created or gathered). Never upgrade a plan into a possession: "we would collect it from partners" is build.
7. **Who checks it.** Nobody, the user, a staff member before it reaches the user, a staff member after, or an expert on a sample.

Anything the founder did not say is a guess and stays marked "(guess)" through the recap and into the PRD, where it reads "unconfirmed." If two rows do not fit together (a trained model with nobody checking; a password sign-in for users with no email), it goes in the recap as one line.

When they answer, go straight to Bets.
